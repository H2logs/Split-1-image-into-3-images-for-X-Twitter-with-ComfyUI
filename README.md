# Split-1-image-into-3-images-for-X-Twitter-with-ComfyUI
A subgraph to split one image into 3 images, increasing the number of views and interactions on X/Twitter.

You can select Y Mirror to apply a vertical symmetry.

Drag the 3 files on X that start with the name "DRAG_THOSE_FILES_ON_X", and it's ready to publish.

Do a right click on the subgraph and select "Add subgraph to Librairy".
